# 叙事设计（Narrative Design）

## 适用
故事驱动的 2D 游戏：剧情关卡、NPC 对话、世界观设定、分支叙事（Ink/Twine 或引擎内对话系统）。

## 叙事结构
1. **三幕/节拍（Beat Sheet）**：钩子 → 上升 → 转折 → 高潮 → 收尾；每关至少一个"情绪节拍"（新信息/反转/抉择）。
2. **角色**：每个角色写"目标+阻碍+秘密"三件套；对话要体现角色声线（不说教、有立场）。
3. **分支与后果**：分支数控制（2-3 个关键抉择点即可）；每个抉择有可感知后果（角色反应/结局变化）。
4. **世界观一致**：建术语表（地名/势力/时间线），所有文案引用同一事实源，避免穿帮。

## 对话编写
- 每条对话 ≤ 2 屏文字；有动作描述（`[叹气]`、`[指向地图]`）。
- 信息密度：一句对白只推进一个信息点。
- 本地化友好：避免双关/俚语依赖，文案走 game-localization 技能做多语言。

## 与玩法衔接
- 叙事节拍对齐关卡结构（boss 前给剧情高潮，探索段给世界观碎片）。
- 选项不造假分支：玩家能感知后果。

## 检查清单
- [ ] 世界观术语表已建，全文案引用一致
- [ ] 每关有情绪节拍
- [ ] 关键抉择 ≤ 3 个，后果可感知
- [ ] 对话无超长段（≤2 屏）
- [ ] 与关卡设计师对齐节拍表

## 交接
- 产出：剧情大纲（beat sheet）+ 对话表/脚本文件 + 术语表 + 待美术/音效配合项。
